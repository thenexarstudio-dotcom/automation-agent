# Consultant Client Ops Kit — Start Here

Thanks for picking up the Kit. Here's what's inside and how to use it.

## What's in this download

Each document in this Kit comes in two formats:

- **`pdf/` folder** — polished, print-ready PDFs. Best for reference and for printing.
- **`markdown/` folder** — the same documents as editable `.md` files. This is the format you'll actually work in.

## Using the editable versions

The markdown files import cleanly into the tools you already use:

- **Notion:** In any Notion page, go to `⋯ → Import → Text & Markdown` and select the file. Tables, checklists, and headings carry over.
- **Google Docs:** Open the `.md` file in any text editor, copy the contents, and paste into a Doc — or use Google Docs' `File → Open` with the file directly (Docs converts markdown natively).
- **Word / anywhere else:** Markdown is plain text; paste it anywhere and apply your own styles, or use a free converter like Pandoc.

## Recommended first steps

1. Start with **08-rate-card-template** and set your three tiers using your real numbers (the free Day Rate Calculator at consultantclientops.com/tools/freelance-day-rate-calculator helps here).
2. Adapt **01-consulting-proposal** and **03-service-agreement** once, with your standard terms, so every future client is a fill-in-the-blanks exercise.
3. Keep **05-change-order** somewhere you can grab it fast — its value is in being sent the same day a client asks for "one more small thing."

## The document flow

Proposal → Service Agreement (+ Scope of Work as Exhibit A) → Onboarding Questionnaire → Kickoff Checklist → Weekly Updates → Change Orders as needed → Invoice → Offboarding Checklist → Testimonial & Referral Scripts → Retainer Agreement for the clients worth keeping.

## A note on the legal documents

The Service Agreement and Retainer Agreement are structured starting points reflecting common practice — not legal advice. Have a lawyer adapt them to your jurisdiction before relying on them for high-value engagements.
